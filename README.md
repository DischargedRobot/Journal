# Journal

Журнал успеваемости для ВУЗа

### Ошибки

Есть код
1х.2х.3х
1х = 0 если клиентская ошибка
=1 если серверная
=2 если ошибка авторизации
2х = 0 если никчему не относится
=1 если отноится к телу запроса
=2 если к полю тела
=3 если параметр запроса
=4 если к заголовку
3х = 0 если пустое
=1 если ошибка, но формат верный
=2 если формат не верный
=3 если нет записи
